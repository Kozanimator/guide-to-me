# Totally Accurate Guide to Me

DG8002 Activity 6 - Stephan Kozak

A simple two-page website in HTML only. No CSS or JavaScript.

- Website: https://kozanimator.github.io/guide-to-me/
- Public repository: https://github.com/Kozanimator/guide-to-me

## Files

- `index.html`: introduction, origin story, skills, and external link.
- `Classified.html`: three fun facts, four-step survival guide, weaknesses, ambitions.
- `images/`: two original illustrations.

Both pages use headings, paragraphs, `header`, `nav`, `main`, `section`, and
`footer`. The homepage also uses a `div` to group its introduction and image.
Each image has descriptive text.
