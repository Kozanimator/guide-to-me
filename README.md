# Totally Accurate Guide to Me

DG8002 Activity 6 - Stephan Kozak

A simple two-page website using only HTML. No CSS or JavaScript.

- Website: https://kozanimator.github.io/guide-to-me/
- Public repository: https://github.com/Kozanimator/guide-to-me

## Files

- `index.html`: introduction, origin story, three skills, and an external link.
- `Classified.html`: three fun facts, a four-step survival guide, weaknesses, and ambitions.
- `images/`: two original illustrations.

Both pages use headings, paragraphs, `header`, `nav`, `main`, `section`, and
`footer`. The homepage also uses a `div` to group its introduction and image.
Each image has descriptive alternative text.

## View or edit

Open `index.html` in a browser to view the site. Keep the `images` folder beside
the HTML files. Open either HTML file in a plain-text editor to change its content.

GitHub Pages publishes the `main` branch from the repository's root folder.

Submit both links above through D2L.
